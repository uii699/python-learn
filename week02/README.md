# 第 2 课：函数——给你的代码起名字

你已经会写代码了（age.py、guess.py 就是证据）。
这一课解决一个新问题：**同一段代码想用第二次，难道要抄一遍吗？**

不用。把代码装进一个「函数」里，给它起个名字，以后喊名字就能用。

## 关卡列表（按顺序做，每关跑通再进下一关）

1. `step1_first_function.py` — 认识函数：定义一个，调用一个
2. `step2_parameters.py` — 参数：让函数每次干活能收到不同的原料
3. `step3_return.py` — 返回值：让函数把算好的结果交回给你
4. `step4_practice.py` — 实战：把猜数字游戏改造成函数版

## 怎么学

- 每个文件先自己敲一遍（别复制！敲才是学）
- 敲完保存，终端跑：`python week02/step1_first_function.py`（文件名换着来）
- 看输出，对照注释理解每一行
- 跑通一关，改点东西再跑一次，看看会发生什么——改坏也没关系
